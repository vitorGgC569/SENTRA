# SENTRA workspace status

The Canvas is the working area of a selected Dot. It presents existing terminals,
files, review, browser/computer tools and activity in contextual tabs and split
panels. The main conversation, project navigation, permissions and execution
authority remain shared with the rest of SENTRA.

## Available in the current source

- Conversation-first Home with a visual assistant selector on the central Dot.
  Existing Dots can be selected; creating one uses the normal confirmed flow.
- Simple and advanced workspace modes, contextual sessions, split panels,
  saved layouts and protected drafts.
- Durable terminal receipt recovery, explicit input ownership and read-only
  reconciliation without automatic replay of uncertain input.
- Shared desktop/mobile conversation observations over authenticated LAN/VPN
  transport; pairing and permissions remain host-controlled.
- Agent coordination, optional Git worktrees and centrally admitted actions.

Implemented source is not the same as complete installed-product qualification.
The local Windows UI has been updated, while the published Setup is older.
External model responses, physical mobile devices, complete recovery journeys,
signing and clean-install/update/rollback acceptance remain open.
