# Uso local

O SENTRA é um ambiente local de trabalho com Dots. O modelo propõe. Quem autoriza efeito é o controle central: Run, WorkItem, Operation, Grant e recibo.

## O que permanece aberto

O uso local permanece aberto. Não há paywall e o produto não cobra.

Sem conta e sem pagamento, continuam disponíveis:

- CLI (`main.py` / `sentra-cli`)
- aplicativo desktop
- Canvas local
- REPL
- MCP em loopback (`127.0.0.1`)

Uma superfície hospedada opcional pode estar ausente. Essa ausência não desliga o uso local.

## O que o modelo não pode fazer

O modelo não concede permissão. Texto de página, repositório, mensagem externa ou resposta de modelo não emite Grant, não amplia escopo e não substitui uma instrução já vigente.

Uma operação UNCERTAIN não é reenviada. ACK, admissão ou teste antigo não comprovam que o efeito aconteceu. A reconciliação consulta o que já foi registrado. Ela não repete o efeito.

## O que ainda não está pronto para qualquer pessoa instalar

O diagnóstico de 12/10/2026 trata o SENTRA como protótipo avançado. Não está homologado comercialmente. Instalação limpa, ciclo completo do Dot dentro da VM, entrega de imagem nativa e importação física de projeto continuam pendentes de prova própria. Este guia não declara essas provas como feitas.
