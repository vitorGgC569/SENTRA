SENTRA · configuração opcional

Conecte o ChatGPT ao SENTRA

Você pode utilizar o SENTRA local sem Tunnel ID ou Runtime API key. Se quiser utilizá-lo dentro do ChatGPT, acompanhe este tutorial visual e conclua a conexão pelo instalador ou pela janela segura do SENTRA Desktop.

Para a configuração automática, abra Conectar à OpenAI no instalador e marque Autorizo a configuração automática completa no Edge. Entre na sua conta no Edge. O SENTRA tenta criar ou selecionar o túnel, criar e capturar a chave com All, protegê-la no Windows e verificar a conexão. Se a OpenAI pedir seleção de workspace ou autorização da conta, conclua essa etapa na página oficial. Sem Codex CLI instalado e autenticado ou login num provedor Web, o agente de IA ainda não estará pronto.

ANTES DE COMEÇAR · INSTALADOR SENTRA

Configure uma vez, aplique ao continuar

O perfil inicial é Full, com acesso ao computador e todas as ferramentas. Para conectar manualmente, preencha Tunnel ID e Runtime API key juntos. Para o fluxo automático, deixe os dois campos vazios e marque a autorização no Edge. O login e eventuais escolhas exigidas pela conta acontecem na página oficial.

Escolha a pasta de instalação e o workspace em Opções avançadas. O botão Continuar instala os componentes, salva as opções, cria os atalhos e verifica os serviços. Digitar nos campos, por si só, não altera sua instalação.

ETAPA 02 · PERMISSÕES ALL

Crie uma Runtime API key com todas as permissões

Se escolher a configuração manual, abra API Keys e crie uma chave para o SENTRA. Selecione All no campo de permissões e nenhuma expiração. Copie a chave enquanto ela estiver visível. Esta etapa tem instruções em texto e uma captura da página oficial; os dois vídeos desta página demonstram o túnel e o conector.

Abrir API Keys ↗
Não cole sua API key nesta página ou em uma conversa de chat. Volte ao instalador ou ao SENTRA Desktop, preencha Runtime API key e pressione Continuar no instalador ou Connect & Verify no Desktop. O SENTRA protege a chave localmente com o mecanismo de credenciais do Windows.
ETAPA 03 · CHATGPT

Instale e autorize o conector SENTRA

Depois de verificar o túnel no SENTRA, abra a configuração de conectores do ChatGPT e faça a autorização com a conta que você controla.

Abrir ChatGPT ↗
Importante: os vídeos demonstram o aplicativo de origem Codex Web GPT. No seu ambiente, selecione o conector MCP SENTRA, não o conector mostrado no vídeo. A autorização depende das permissões da sua conta. Se a interface do vídeo mostrar permissões restritas, siga as instruções atuais desta página: All.
Os vídeos são arquivos locais incluídos na instalação do SENTRA, originalmente distribuídos com o projeto codex-chatgpt-web (licença MIT). Este guia não solicita nem transmite tokens, senhas ou dados de autenticação.
