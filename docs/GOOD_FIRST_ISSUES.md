# Good first issues

These are small, independently reviewable tasks. Check the [issue tracker](https://github.com/vitorGgC569/SENTRA/issues) before starting and comment on the relevant issue to coordinate.

1. [Check documentation links](https://github.com/vitorGgC569/SENTRA/issues/3).
2. [Improve a CLI configuration error](https://github.com/vitorGgC569/SENTRA/issues/4).
3. [Document API and local model configuration](https://github.com/vitorGgC569/SENTRA/issues/5).
4. [Improve keyboard accessibility of a desktop dialog](https://github.com/vitorGgC569/SENTRA/issues/6).
