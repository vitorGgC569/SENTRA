# SENTRA product presentation — 24 October 2026

This delivery refreshes the public presentation. It does not qualify a stable
release or replace the published Windows installer.

- README and product-facing Markdown notes use SENTRA terminology. Historical
  source records were preserved byte-for-byte with an indexed SHA-256 inventory;
  required licenses remain in the separate third-party notices.
- Home, assistant selection and split-Canvas screenshots were captured from the
  current UI with isolated demonstration data at 1280 × 720. No provider response
  or real agent execution is implied by the screenshots.
- The download catalog verifies published asset metadata before showing a
  Windows preview. The October 23 installer is explicitly older than the local
  interface; Android preview v7 is available and iPhone distribution is pending.
- Visible component credit labels were made product-neutral while the actual
  license contents and component metadata remain intact. Production UI assets
  were rebuilt successfully; the installed executable was not rebuilt in this
  documentation/site delivery.

Validation: 265 desktop UI tests, 20 Python site/catalog tests and 7 JavaScript
download-rendering tests passed. The site build consumed the actual published
release manifests. Local browser review checked English copy, release URLs,
download states and the absence of horizontal overflow. Updated README media
hashes, contributor images, archived source hashes and local Markdown targets
were checked.

See [first-version readiness](RELEASE_READINESS_2026-10-24.md) for the remaining
acceptance gates. Complete Setup generation, signing, clean install/update/
rollback, installed endurance, real-provider/multi-Dot recovery and physical
mobile acceptance are separate work.
